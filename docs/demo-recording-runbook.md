# Image Master 演示录制 Runbook

这份流程用于录制无敏感信息的项目展示。默认不展示设置页里的 Key，不展示 `.env`，不展示私人素材。

## 1. 演示前配置

主用 API：

```text
https://slb.apikey.fun/v1
```

备用 API：

```text
https://api.apikey.fun/v1
```

三类模型建议统一：

```text
visionModel: gpt-5.5
imageModel: gpt-5.5
textModel: gpt-5.5
```

如果专线异常，只在设置页把 provider 切到 `APIKey.fun 备用`，不要在录制中展示 Key。

## 2. 录制前检查

```bash
npm run typecheck
npm run smoke:agent-plan-20
npm run smoke:agent-output-scenarios
```

真实 provider 只需要先测一张：

```text
生成一个无品牌实物产品静物图，确认专线能返回图片即可。
```

不要在正式录制里现场跑大批量真实生图；大图组用已经跑通的结果或小批量展示。

## 3. 推荐演示项目

使用一个无品牌真实感产品，避免商标和敏感信息。

推荐产品：

```text
黑色磨砂陶瓷随行杯 / 保温杯
```

推荐项目需求：

```text
给这个黑色磨砂随行杯做一套电商与社媒宣传图。需要商品主图、商品细节、使用场景、海报图、小红书封面和详情页卖点图。部分海报需要把短文案直接放进画面安全区，普通商品图不要烧字。整体要真实商业摄影质感，不要廉价合成感。
```

推荐短文案：

```text
标题：通勤路上，热饮刚好
卖点：磨砂握感 / 密封杯盖 / 轻巧随行
禁止：不要写官方认证、医疗效果、绝对保温时长
```

## 4. 录制主线

1. 打开项目画布。
2. 展示素材库：商品、模特、场景、风格、文案。
3. 上传或选中商品参考图。
4. 在右上角 Agent 输入上面的项目需求。
5. 展示 Agent 规划：用途、比例、参考图角色、文案是否烧进图。
6. 展示结果墙：不同尺寸图片按真实比例铺在无限画布上。
7. 点开一张海报：查看大图、prompt、参考图、provider 信息。
8. 点击修改，把这张图交给 Agent，说一句修改要求。
9. 打开本地文件夹，展示可交付结果。

## 5. 录制时不要说

- 不要说已经公开生产可用。
- 不要承诺 provider 永远稳定。
- 不要承诺商品细节像素级复刻。
- 不要承诺模特身份 100% 一致。
- 不要展示 API Key、`.env`、私有项目、私人聊天窗口。

## 6. 可以说

- 这是内部可试用的商业图片 Agent 工作台。
- 用户用项目管理资产，用自然语言交给 Agent 规划整套图。
- Agent 会判断比例、用途、参考图和文案策略。
- 商品真实身份需要真实商品参考图。
- 每张结果都能追溯 prompt、参考图和 provider 信息。
- 不满意可以点图后继续让 Agent 修改。
